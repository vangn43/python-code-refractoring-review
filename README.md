# Python Code Refactoring Review

## Project Description

This project is focused on improving an existing Python script by making the code easier to read and understand. I updated the function and variable names, added docstrings and comments, and makde the code shorter using list comprehensions. The goal was to improve the code without changing the original results.

## What the Program Does

The program processes two lists, one containing numbers and another ocntaining words.

- For numbersm even numbers are multiplied by 2 and odd numbers are multiplied by 3.
- For words, words longer than 5 characters are changed to uppercase, while shorter words are changed to lowercase.
- The program prints the results after processing both lists.

## How to Run the Program

1. Make sure Oython 3 is installed on your computer.
2. Downlaod the `undocumented_script.py` file.
3. Open the file in VS Code or another  code editor.
4. Run the program using the terminal:

  python undocumented_script.py

5. The program will display the processed numbers and words.

## Expected Output

  Processed Numbers" [3, 4, 9, 8, 15, 12, 21]
  Processed Strings: apple BANANA kiwi GRAPEFRUIT CHERRY
